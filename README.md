# mc-tool
Minecraft Manifest Json Editor / UUID Generator


## Usage
- Offline use: Download [Source.zip](https://github.com/xetsue/mc-tool/releases/tag/v1.0) , unzip, open `index.html` in any browser.

- [Online Use](https://xetsue.github.io/mc-tool/)
